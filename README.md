# Bruna Sousa — Cartão de visitas digital

Página estática, responsiva, pronta para GitHub Pages. Não requer instalação nem build.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `contato`).
2. Envie **os arquivos e a pasta `assets` de dentro deste ZIP** para a raiz do repositório (não envie a pasta externa inteira).
3. Em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**.
4. Selecione a branch `main`, a pasta `/(root)` e clique em **Save**.
5. Após a publicação, o endereço normalmente será `https://SEU-USUARIO.github.io/contato/` (troque pelo usuário e nome do repositório reais).
6. Use esse endereço para gerar o QR Code da palestra.

## Arquivos
- `index.html`: estrutura e contatos
- `styles.css`: identidade visual clara, grafite e amarelo
- `script.js`: ano automático no rodapé
- `assets/logo-bruna-sousa.png`: logomarca horizontal fornecida
- `assets/brand-symbol.png`: símbolo da marca, usado como favicon

## Alterações futuras
Edite os links `mailto:`, LinkedIn e Instagram no `index.html`. A página funciona também em repositórios de projeto, sem caminho absoluto.

## Privacidade
Nenhum rastreador, formulário, biblioteca externa ou serviço de terceiros é carregado pela página. Ao clicar nos links, o visitante é encaminhado para a plataforma escolhida.
